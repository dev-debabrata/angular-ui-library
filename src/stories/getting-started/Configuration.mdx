# Configuration

NexPrime is styled with CSS variables from one stylesheet, so you configure it with CSS, the same way in every
framework. Set up the package first (**Installation**).

## Dark mode

Set `data-theme="dark"` on `<html>`. Every component switches: the neutral colors, borders, shadows and tones have
dark values, and the brand colors stay as they are.

```html
<html data-theme="dark"></html>
```

```ts
// Toggle it, e.g. from a switch, and follow the system setting by default
const dark = matchMedia('(prefers-color-scheme: dark)').matches;
document.documentElement.dataset['theme'] = dark ? 'dark' : 'light';
```

## Brand colors

Override three variables after the theme. The soft background (`--ui-primary-soft`), focus ring and gradient are
derived from them, so they follow automatically, in light and dark mode:

```css
:root {
  --ui-primary: #14b8a6; /* buttons, links, selected states */
  --ui-primary-hover: #0d9488;
  --ui-accent: #0ea5e9; /* the gradient goes from primary to accent */
}
```

The theme menu in this Storybook's toolbar tries the built-in palettes: Indigo (default, `#6366f1` → `#a855f7`),
Violet, Purple, Fuchsia, Pink, Rose, Red, Orange, Amber, Green, Emerald, Teal, Cyan, Sky, Blue, Slate, Navy,
Midnight, Plum, Wine, Brown, Forest, Ocean and Graphite. Its **Custom** row adds your own: click **+**, pick any
color, and the theme uses it (hover and accent shades are derived from it). Your colors are kept in this browser, and
a hovered swatch's **×** removes one.

## Color and shape per component

Add an appearance class to **any** component (or a wrapper around several) to recolor or reshape it and everything
inside it. It works the same in Angular, React (`className`), Vue and HTML:

```html
<np-select class="np-color-success np-shape-rounded" label="Status" />
<np-button class="np-color-danger" primary label="Delete" />
<np-toggle class="np-color-teal" label="Teal, from the palette" />
<np-button class="np-color-custom" style="--np-color: #ff6a00" primary label="Any color" />
<div class="np-shape-square">… every component in here has square corners …</div>
```

The **Playground** has a color and shape picker that works on every component.

**Button** also has its own options: `severity` (the 8 colors above), `variant` (`solid` | `outlined` | `text` |
`soft`), `shape` (`pill` | `rounded` | `square`), `icon` with `iconPos`, `loading` and `disabled`.

## Icons

`<np-icon name="house" />`, and every component that shows an icon, loads `<name>.svg` from an icons folder at
runtime. The package ships all 1,500+ Lucide icons in `nexprime/icons`. Serve them in one of two ways:

- **From your app**, at `/icons` (the default location):
  - Angular, in `angular.json` assets: `{ "glob": "**/*.svg", "input": "node_modules/nexprime/icons", "output": "icons" }`
  - Vite, Next.js and others: copy `node_modules/nexprime/icons` to `public/icons`.
- **From the CDN**, with no copying: set the folder once, before the first icon renders:

  ```ts
  window.NEXPRIME_ICONS_URL = 'https://cdn.jsdelivr.net/npm/nexprime/icons/';
  // React and Next.js: setIconsUrl(...) from 'nexprime/react'
  ```

**Your own icons:** put `.svg` files in the same folder (e.g. `public/icons/my-logo.svg`) and use
`<np-icon name="my-logo" />`. Outline icons that use `currentColor` also get the `duotone`, `gradient`, `soft` and
`solid` variants. The **Icons** page lets you search, customize and copy every icon.

## Lottie animations

`<np-lottie src="…">` plays any Lottie `.json` or `.lottie` URL. The starter animations from the **NexLottie** page are
in `nexprime/lottie`. Serve that folder like the icons (Angular assets:
`{ "glob": "**/*.json", "input": "node_modules/nexprime/lottie", "output": "lottie" }`), or use the CDN:

```html
<np-lottie src="https://cdn.jsdelivr.net/npm/nexprime/lottie/success.json"></np-lottie>
```

## CSS animations

`theme.css` includes the `np-anim-*` classes. They work on any element, not only NexPrime components:

```html
<div class="np-anim-fade-up" style="--np-anim-duration: 600ms; --np-anim-delay: 150ms">Hello</div>
```

## Confirm dialogs

- **Angular:** inject `ConfirmationService` from `'nexprime'` and call
  `confirm({ header, message, accept, reject })`. Put `<np-confirm-dialog />` (or `<np-confirm-popup />` with
  `target: event.currentTarget`) in your template once.
- **Web Components:** put `<np-confirm-dialog>` on the page and call
  `window.NexPrime.confirm({ header, message, accept, reject })`.

## Server-side rendering

- **Angular SSR**: every component renders on the server and hydrates; browser-only work (icons, charts' sizes,
  effects, Lottie) starts after hydration.
- **Next.js, Nuxt, SvelteKit, Astro**: load the elements in the browser only (the React wrapper does this for you;
  elsewhere, import `nexprime/elements` in an `onMount`/client-only script).
