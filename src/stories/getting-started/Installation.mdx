# Installation

NexPrime is one npm package for every framework. **Angular** apps use the components directly; **React, Next.js,
Vue, Svelte and plain HTML** use the same components as standard **Web Components** (custom elements) that come in
the same package.

```bash
npm install nexprime
```

Every framework also loads the theme once (`nexprime/styles/theme.css`) and serves the icons. See
**Configuration** for colors, dark mode, icons and animations.

## Angular

```bash
npm install nexprime @angular/cdk
```

**1.** Add the theme to your global styles (`src/styles.css`):

```css
@import 'nexprime/styles/theme.css';
```

**2.** Serve the icons at `/icons`, where `<np-icon>` looks for them. In `angular.json`, under
`architect.build.options.assets`:

```json
{ "glob": "**/*.svg", "input": "node_modules/nexprime/icons", "output": "icons" }
```

**3.** Import the components you use:

```ts
import { Component, signal } from '@angular/core';
import { ChartComponent, ToggleComponent } from 'nexprime';

@Component({
  selector: 'app-dashboard',
  imports: [ChartComponent, ToggleComponent],
  template: `
    <np-toggle label="Dark mode" [(checked)]="dark" />
    <np-chart type="line" [labels]="labels" [datasets]="data" />
  `,
})
export class Dashboard {
  dark = signal(false);
  labels = ['Q1', 'Q2', 'Q3', 'Q4'];
  data = [{ label: 'Sales', data: [120, 150, 170, 210] }];
}
```

Shared types (`Tone`, `MenuItem`, `TreeNode`, …) and `ConfirmationService` come from `'nexprime'` too.

## React (18 and 19)

```bash
npm install nexprime
```

Load the theme once, in `main.tsx`:

```tsx
import 'nexprime/styles/theme.css';
```

Render components with the `NexPrime` wrapper. It loads the elements in the browser, sets arrays and objects as
**properties** and adds the **event listeners**:

```tsx
import { useMemo, useState } from 'react';
import { NexPrime, setIconsUrl } from 'nexprime/react';

setIconsUrl('https://cdn.jsdelivr.net/npm/nexprime/icons/'); // or copy node_modules/nexprime/icons to public/icons

// Outside the component, so the same array is reused on every render
const fields = [
  { name: 'email', label: 'Email', type: 'email', required: true },
  { name: 'password', label: 'Password', type: 'password', minLength: 8, required: true },
];

export function Signup() {
  const [account, setAccount] = useState<Record<string, unknown> | null>(null);
  const on = useMemo(() => ({ submitted: (e: CustomEvent) => setAccount(e.detail) }), []);
  return <NexPrime tag="np-form" card title="Create account" submit-label="Sign up" props={{ fields }} on={on} />;
}
```

- `tag` is the element name. Strings, numbers and booleans are plain attributes (`submit-label="Sign up"`, `card`);
  arrays, objects and functions go in `props`; outputs go in `on` (the value is `event.detail`).
- Keep `props` and `on` stable (constants outside the component, `useMemo`): a new object on every render sets the
  properties and re-adds the listeners each time.
- Elements that only take attributes can be written as plain tags: `<np-icon name="rocket" size="32" />`. TypeScript
  accepts every `np-*` tag once `nexprime/react` is imported.
- Without the wrapper, `import 'nexprime/elements'` once. React 19 then sets object props as properties and
  `on<event>` props as listeners (`onsubmitted`, `onvalueChange`).

## Next.js (App Router)

```bash
npm install nexprime
```

Next.js renders pages on the server, before the elements exist in the browser. The `NexPrime` wrapper handles this:
it loads the elements only in the browser and sets properties and listeners once they're defined, so it works in
server and client components.

**1.** Load the theme in `app/layout.tsx`:

```tsx
import 'nexprime/styles/theme.css';
```

**2.** Use the wrapper. In a **server component**, data can be passed directly:

```tsx
import { NexPrime } from 'nexprime/react';

export default function Page() {
  return (
    <NexPrime
      tag="np-chart"
      type="bar"
      props={{ labels: ['Q1', 'Q2', 'Q3', 'Q4'], datasets: [{ label: 'Sales', data: [120, 150, 170, 210] }] }}
    />
  );
}
```

Event handlers are functions, so they need a **client component** (`'use client'`), as in the React example.

- Icons: copy `node_modules/nexprime/icons` to `public/icons`, or call `setIconsUrl()` with the CDN folder in a
  client component.
- Plain `<np-*>` tags (without the wrapper) need the elements loaded: call `loadNexPrime()` from `nexprime/react`
  once in a client component's `useEffect`.

## Vue 3

```bash
npm install nexprime
```

Tell Vue these are custom elements (`vite.config.ts`):

```ts
vue({ template: { compilerOptions: { isCustomElement: (tag) => tag.startsWith('np-') } } });
```

Load the theme and the elements once (`main.ts`):

```ts
import 'nexprime/styles/theme.css';
import 'nexprime/elements';

window.NEXPRIME_ICONS_URL = 'https://cdn.jsdelivr.net/npm/nexprime/icons/';
```

```vue
<template>
  <np-chart type="bar" :labels="labels" :datasets="datasets" />
  <np-button-toggle :options="options" :value="period" @value-change="period = $event.detail" />
  <np-chat title="Support" :messages="messages" @send="reply($event.detail)" />
</template>
```

Vue passes arrays and objects as properties automatically. Use the kebab-case event names (`@value-change`).

## Svelte 5 (and SvelteKit)

```bash
npm install nexprime
```

Load the theme and the elements once, and mount the app after they're defined (`src/main.ts`), so Svelte sets
arrays and objects as properties:

```ts
import 'nexprime/styles/theme.css';
import 'nexprime/elements';
import { mount } from 'svelte';
import App from './App.svelte';

window.NEXPRIME_ICONS_URL = 'https://cdn.jsdelivr.net/npm/nexprime/icons/';
await customElements.whenDefined('np-button');
mount(App, { target: document.getElementById('app')! });
```

```svelte
<script lang="ts">
  let labels = ['Q1', 'Q2', 'Q3'];
  let datasets = [{ label: 'Sales', data: [120, 150, 170] }];
</script>

<np-chart type="bar" {labels} {datasets}></np-chart>
<np-button primary label="Save" onclicked={() => console.log('saved')}></np-button>
```

In **SvelteKit**, load the elements in the browser only: `onMount(() => import('nexprime/elements'))` in your root
`+layout.svelte`, and import the theme there.

## Other frameworks (Solid, Preact, Astro, Lit, …)

Anything that renders HTML can use the elements:

1. `npm install nexprime`
2. Import `nexprime/styles/theme.css` and `nexprime/elements` once, in the browser (not during server rendering).
3. Set `window.NEXPRIME_ICONS_URL` to where the icons are served (the CDN folder or a copy of `node_modules/nexprime/icons`).
4. Write `<np-*>` tags. Pass arrays and objects as **properties** and listen to outputs as **DOM events**
   (see the rules below).

## Plain HTML (CDN)

No install and no build step:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/nexprime/styles/theme.css" />
<script>
  window.NEXPRIME_ICONS_URL = 'https://cdn.jsdelivr.net/npm/nexprime/icons/';
</script>
<script type="module" src="https://cdn.jsdelivr.net/npm/nexprime/elements/nexprime.js"></script>

<np-chart id="sales" type="line"></np-chart>
<script type="module">
  await customElements.whenDefined('np-chart');
  const chart = document.getElementById('sales');
  chart.labels = ['Q1', 'Q2', 'Q3', 'Q4'];
  chart.datasets = [{ label: 'Sales', data: [120, 150, 170, 210] }];
</script>
```

Pin a version in production: `https://cdn.jsdelivr.net/npm/nexprime@0.1.1/…`.

## Web Component rules (React, Vue, HTML)

- **Tag names** are the same as in Angular: `<np-form>`, `<np-voice-chat>`, `<np-chart>`.
- **Strings, numbers and booleans** can be HTML attributes in kebab-case: `num-visible="3"`, `card`,
  `submit-label="Send"`.
- **Arrays, objects and functions** (`datasets`, `fields`, `items`, `options`, `format`) must be set as
  **properties**. Vue, React 19 and the `NexPrime` wrapper do this for you; in plain JS write `el.fields = [...]`.
- **Outputs are DOM events** with the output's name (`submitted`, `valueChange`, `send`); the value is
  `event.detail`. camelCase events are also sent in kebab-case (`valueChange` and `value-change`).
- **Content**: children are projected once, when the element starts (e.g. Card body, Dialog content,
  `formBeforeActions`).
- **Carousel**: without an Angular `<ng-template>`, each **child element is a slide**.
- **Confirm dialogs**: put `<np-confirm-dialog>` (or `-popup`) on the page and call
  `window.NexPrime.confirm({ header, message, accept, reject, target })`.
- The elements register asynchronously; a `nexprime:ready` event fires on `window` when they are ready.
- **Angular-only features:** custom item templates (`<ng-template>`) for Pick List and Timeline; the Web Components
  use their default layout.
