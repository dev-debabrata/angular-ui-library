# Use NexPrime in React, Vue & Angular

NexPrime is written in Angular. **Angular apps** use the components directly. **React, Next.js, Vue, Svelte and plain
HTML** use the same components as standard **Web Components** (custom elements), built from this repo.

## 1. Build the Web Components

```bash
npm run build:elements
```

This creates `dist/nexprime-elements/browser/`:

- `nexprime.js`: every component, registered as `<np-*>` elements (about 116 KB gzipped, includes the Angular runtime once)
- `styles.css`: the theme (colors, buttons, form fields) and the `np-anim-*` animations
- `icons/`: the SVG icons used by `<np-icon>` and inside components

Copy that folder into your app's public/static folder (for example `public/nexprime/`), then load it once:

```html
<link rel="stylesheet" href="/nexprime/styles.css" />
<script type="module" src="/nexprime/nexprime.js"></script>
<script>
  // Icons load from "icons/" next to the page by default
  window.NEXPRIME_ICONS_URL = '/nexprime/icons/';
</script>
```

The elements register asynchronously; a `nexprime:ready` event fires on `window` when they are ready.

## 2. Rules that apply everywhere

- **Tag names** are the same as in Angular: `<np-form>`, `<np-voice-chat>`, `<np-chart>`.
- **Strings, numbers and booleans** can be HTML attributes in kebab-case: `num-visible="3"`, `card`, `submit-label="Send"`.
- **Arrays, objects and functions** (`datasets`, `fields`, `items`, `options`, `format`) must be set as
  **properties**. Vue and React 19 do this for you; in plain JS write `el.fields = [...]`.
- **Outputs are DOM events** with the output's name (`submitted`, `valueChange`, `send`); the value is `event.detail`.
  camelCase events are also sent in kebab-case (`valueChange` and `value-change`).
- **Content**: children are projected once, when the element starts (e.g. Card body, Dialog content, `formBeforeActions`).
- **Carousel**: without an Angular `<ng-template>`, each **child element is a slide**.
- **Confirm dialogs**: put `<np-confirm-dialog>` (or `-popup`) on the page and call
  `window.NexPrime.confirm({ header, message, accept, reject, target })`.

## React (19+)

```jsx
export function Signup() {
  return (
    <np-form
      card
      title="Create account"
      submit-label="Sign up"
      fields={[
        { name: 'email', label: 'Email', type: 'email', required: true },
        { name: 'password', label: 'Password', type: 'password', minLength: 8, required: true },
      ]}
      onsubmitted={(e) => console.log(e.detail)}
    />
  );
}

<np-carousel num-visible="3" circular autoplay-interval="3000">
  {products.map((p) => (
    <div key={p.id}>{p.name}</div>
  ))}
</np-carousel>;
```

React 19 sets object props as properties and `on<event>` props as listeners (`onsubmitted`, `onvalueChange`).
This needs `nexprime.js` loaded before React renders; with server rendering (Next.js, Remix) use the wrapper below.
On **React 18**, use a ref: `ref.current.fields = [...]` and `ref.current.addEventListener('submitted', …)`.

TypeScript: declare the tags once, e.g. in `src/nexprime.d.ts`:

```ts
import 'react';
declare module 'react' {
  namespace JSX {
    interface IntrinsicElements {
      [tag: `np-${string}`]: any;
    }
  }
}
```

## Next.js (App Router)

Next.js renders pages on the server and then **hydrates** them, before `nexprime.js` has registered the elements.
Strings, numbers and booleans work as attributes, but arrays, objects and event handlers that React sets during
hydration are lost. A small client wrapper solves this: it waits for the element to be defined, then sets the
properties and listeners. It works in server and client components, and on React 18.

**1.** Copy `dist/nexprime-elements/browser/` to `public/nexprime/` (copy the whole folder: `nexprime.js` loads chunk files
next to it).

**2.** Load the theme and the elements in `app/layout.tsx`:

```tsx
import Script from 'next/script';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <head>
        <link rel="stylesheet" href="/nexprime/styles.css" />
      </head>
      <body>
        {children}
        <Script id="np-config" strategy="beforeInteractive">
          {`window.NEXPRIME_ICONS_URL = '/nexprime/icons/';`}
        </Script>
        {/* After hydration; crossOrigin matches the module request, so the preload is used */}
        <Script src="/nexprime/nexprime.js" type="module" crossOrigin="anonymous" strategy="afterInteractive" />
      </body>
    </html>
  );
}
```

**3.** Add the wrapper, `components/nexprime.tsx`:

```tsx
'use client';
import { createElement, useEffect, useRef, type ReactNode } from 'react';

type NexPrimeProps = {
  /** Element name, e.g. "np-chart" */
  tag: `np-${string}`;
  /** Arrays, objects and functions: set as properties once the element is defined */
  props?: Record<string, unknown>;
  /** Output events, e.g. { submitted: (e) => save(e.detail) } */
  on?: Record<string, (event: CustomEvent) => void>;
  children?: ReactNode;
  /** Anything else (strings, numbers, booleans, id, className, style) is passed as an attribute */
  [attribute: string]: unknown;
};

/** Renders a NexPrime Web Component and gives it its properties and events once nexprime.js has registered it */
export function NexPrime({ tag, props, on, children, ...attributes }: NexPrimeProps) {
  const ref = useRef<HTMLElement>(null);

  useEffect(() => {
    let current = true;
    customElements.whenDefined(tag).then(() => {
      if (current && ref.current) Object.assign(ref.current, props);
    });
    return () => {
      current = false;
    };
  }, [tag, props]);

  useEffect(() => {
    const el = ref.current;
    if (!el || !on) return;
    const listeners = Object.entries(on).map(([name, fn]) => [name, fn as EventListener] as const);
    for (const [name, fn] of listeners) el.addEventListener(name, fn);
    return () => {
      for (const [name, fn] of listeners) el.removeEventListener(name, fn);
    };
  }, [on]);

  // The element fills itself in on the client, so its server HTML is only a placeholder
  return createElement(tag, { ref, ...attributes, suppressHydrationWarning: true }, children);
}
```

**4.** Use it. In a **server component**, data can be passed directly:

```tsx
import { NexPrime } from '@/components/nexprime';

export default function Page() {
  return (
    <NexPrime
      tag="np-chart"
      type="bar"
      props={{ labels: ['Q1', 'Q2', 'Q3', 'Q4'], datasets: [{ label: 'Sales', data: [120, 150, 170, 210] }] }}
    />
  );
}
```

Event handlers are functions, so they need a **client component**:

```tsx
'use client';
import { useMemo, useState } from 'react';
import { NexPrime } from '@/components/nexprime';

// Outside the component, so the same array is reused on every render
const fields = [
  { name: 'email', label: 'Email', type: 'email', required: true },
  { name: 'password', label: 'Password', type: 'password', minLength: 8, required: true },
];

export function Signup() {
  const [account, setAccount] = useState<Record<string, unknown> | null>(null);
  const on = useMemo(() => ({ submitted: (e: CustomEvent) => setAccount(e.detail) }), []);
  return <NexPrime tag="np-form" card title="Create account" submit-label="Sign up" props={{ fields }} on={on} />;
}
```

- Elements that only take attributes can be written directly: `<np-icon name="rocket" size="32" />`.
- Keep `props` and `on` stable (constants outside the component, `useMemo`): a new object on every render
  sets the properties and re-adds the listeners each time.
- Add the TypeScript declaration from the React section (e.g. `nexprime.d.ts` in the project root).
- **Pages Router**: put the `<link>` and the `beforeInteractive` config script in `pages/_document.tsx`, and the
  `nexprime.js` script in `pages/_app.tsx`; the wrapper works the same.

## Vue 3

Tell Vue these are custom elements (`vite.config.ts`):

```ts
vue({ template: { compilerOptions: { isCustomElement: (tag) => tag.startsWith('np-') } } });
```

```vue
<template>
  <np-chart type="bar" :labels="labels" :datasets="datasets" />
  <np-button-toggle :options="options" :value="period" @value-change="period = $event.detail" />
  <np-chat title="Support" :messages="messages" @send="reply($event.detail)" />
</template>
```

Vue passes arrays and objects as properties automatically. Use the kebab-case event names (`@value-change`).

## Angular

Use the components directly (no Web Components needed): copy or import them from `src/stories/components/`
and add them to your component's `imports`:

```ts
@Component({
  imports: [ChartComponent, FormComponent],
  template: `<np-chart type="line" [labels]="labels" [datasets]="data" />`,
})
```

Import `src/stories/styles/theme.css` in your global styles and serve `src/stories/icons/svg` at `/icons`
(see `angular.json` in this repo).

## Plain HTML

```html
<np-chart id="sales" type="line"></np-chart>
<script>
  const chart = document.getElementById('sales');
  chart.labels = ['Q1', 'Q2', 'Q3', 'Q4'];
  chart.datasets = [{ label: 'Sales', data: [120, 150, 170, 210] }];
</script>
```
