# Use NexUI in React, Vue & Angular

NexUI is written in Angular. **Angular apps** install it from npm (`npm install nexui`, see [Angular](#angular))
and use the components directly. **React, Vue, Svelte and plain HTML** use the same components as standard
**Web Components** (custom elements), built from this repo.

## 1. Build the Web Components

```bash
npm run build:elements
```

This creates `dist/nexui-elements/browser/`:

- `nexui.js`: every component, registered as `<nexui-*>` elements (about 116 KB gzipped, includes the Angular runtime once)
- `styles.css`: the theme (colors, buttons, form fields) and the `nex-anim-*` animations
- `icons/`: the SVG icons used by `<nexui-icon>` and inside components

Copy that folder into your app's public/static folder (for example `public/nexui/`), then load it once:

```html
<link rel="stylesheet" href="/nexui/styles.css" />
<script type="module" src="/nexui/nexui.js"></script>
<script>
  // Icons load from "icons/" next to the page by default
  window.NEXUI_ICONS_URL = '/nexui/icons/';
</script>
```

The elements register asynchronously; a `nexui:ready` event fires on `window` when they are ready.

## 2. Rules that apply everywhere

- **Tag names** are the Angular selectors with `nexui-`: `nex-form` → `nexui-form`, `nex-voice-chat` → `nexui-voice-chat`.
- **Strings, numbers and booleans** can be HTML attributes in kebab-case: `num-visible="3"`, `card`, `submit-label="Send"`.
- **Arrays, objects and functions** (`datasets`, `fields`, `items`, `options`, `format`) must be set as
  **properties**. Vue and React 19 do this for you; in plain JS write `el.fields = [...]`.
- **Outputs are DOM events** with the output's name (`submitted`, `valueChange`, `send`); the value is `event.detail`.
  camelCase events are also sent in kebab-case (`valueChange` and `value-change`).
- **Content**: children are projected once, when the element starts (e.g. Card body, Dialog content, `formBeforeActions`).
- **Carousel**: without an Angular `<ng-template>`, each **child element is a slide**.
- **Confirm dialogs**: put `<nexui-confirm-dialog>` (or `-popup`) on the page and call
  `window.NexUI.confirm({ header, message, accept, reject, target })`.

## React (19+)

```jsx
export function Signup() {
  return (
    <nexui-form
      card
      title="Create account"
      submit-label="Sign up"
      fields={[
        { name: 'email', label: 'Email', type: 'email', required: true },
        { name: 'password', label: 'Password', type: 'password', minLength: 8, required: true },
      ]}
      onsubmitted={(e) => console.log(e.detail)}
    />
  );
}

<nexui-carousel num-visible="3" circular autoplay-interval="3000">
  {products.map((p) => (
    <div key={p.id}>{p.name}</div>
  ))}
</nexui-carousel>;
```

React 19 sets object props as properties and `on<event>` props as listeners (`onsubmitted`, `onvalueChange`).
On **React 18**, use a ref: `ref.current.fields = [...]` and `ref.current.addEventListener('submitted', …)`.

TypeScript: declare the tags once, e.g. in `src/nexui.d.ts`:

```ts
import 'react';
declare module 'react' {
  namespace JSX {
    interface IntrinsicElements {
      [tag: `nexui-${string}`]: any;
    }
  }
}
```

## Vue 3

Tell Vue these are custom elements (`vite.config.ts`):

```ts
vue({ template: { compilerOptions: { isCustomElement: (tag) => tag.startsWith('nexui-') } } });
```

```vue
<template>
  <nexui-chart type="bar" :labels="labels" :datasets="datasets" />
  <nexui-button-toggle :options="options" :value="period" @value-change="period = $event.detail" />
  <nexui-chat title="Support" :messages="messages" @send="reply($event.detail)" />
</template>
```

Vue passes arrays and objects as properties automatically. Use the kebab-case event names (`@value-change`).

## Angular

Angular apps (21+) install the **`nexui`** npm package and use the components directly, no Web Components needed.

**1. Install**

```bash
npm install nexui
```

**2. Add the theme** to your global styles (`src/styles.css`):

```css
@import 'nexui/styles/theme.css';
```

**3. Serve the icons** at `/icons`, so `<nex-icon name="…">` can load them. In `angular.json`, under
`build.options.assets`:

```json
{ "glob": "*.svg", "input": "node_modules/nexui/icons", "output": "icons" }
```

**4. Import** components from `nexui` and add them to your component's `imports`:

```ts
import { ChartComponent, FormComponent } from 'nexui';

@Component({
  imports: [ChartComponent, FormComponent],
  template: `<nex-chart type="line" [labels]="labels" [datasets]="data" />`,
})
```

Shared types (`Tone`, `MenuItem`, `TreeNode`, …) and `ConfirmationService` come from `nexui` too. Dark mode is
`data-theme="dark"` on `<html>`.

Building the package from this repo: `npm run build:lib` writes it to `dist/nexui/`. Publish with
`cd dist/nexui && npm publish`, or try it locally first with `npm pack` and `npm install ./nexui-0.1.0.tgz`.

## Plain HTML

```html
<nexui-chart id="sales" type="line"></nexui-chart>
<script>
  const chart = document.getElementById('sales');
  chart.labels = ['Q1', 'Q2', 'Q3', 'Q4'];
  chart.datasets = [{ label: 'Sales', data: [120, 150, 170, 210] }];
</script>
```
