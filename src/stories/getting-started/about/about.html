Why we built it

Most UI libraries belong to a single framework, so teams that use more than one end up rebuilding the same buttons, tables and dialogs, and keeping them in sync by hand.

NexPrime starts from modern Angular (signals, standalone components, server rendering) and ships every component as a Web Component as well. One design, one set of tokens and one package work everywhere, from a React app to a static HTML page.
